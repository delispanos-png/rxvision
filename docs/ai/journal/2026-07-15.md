## Bugs found by testing (would have shipped broken)

- `executed_at` is a **datetime**, not ISO string → cross-tenant sort would raise `TypeError`
  as soon as a second pharmacy had executions. Fixed with `_exec_ts`.
- `/admin/tenants` returns `{items: [...]}`, not an array → `.filter()` crashed the network
  page. TS didn't catch it: the declared type was a lie, not a check.
- `refresh()` used `user["tenant_id"]` → every token refresh kicked a network user back to
  their primary pharmacy.
- `patient_contacts` is keyed by `_id` = patient_ref (no `patient_ref` field) → transfer copy
  wrote nowhere.
- Sticky cart bar at `top-2` sat **over** the portal header; duplicate floating cart button
  overlapped the mobile bottom nav (removed).
- PharmaCat launcher (absolutely centered) covered the pharmacy switcher → switcher moved into
  the left cluster (`mr-auto` on a wrapper, not on the buttons).
