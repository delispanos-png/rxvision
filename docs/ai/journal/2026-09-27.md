### Έξι πράγματα που βρήκα διορθώνοντας, όχι γράφοντας

1. **Ο γενικός χειριστής 404 κατάπινε τα δικά μας 404.** Κάθε «ο ασθενής δεν βρέθηκε» / «ο πελάτης
   δεν είναι συνδεδεμένος» έβγαινε ως «δεν υπάρχει τέτοια διαδρομή» — ο προγραμματιστής θα έψαχνε
   ώρες λάθος πράγμα, σε ένα API που υπόσχεται το αντίθετο. Και η υπόδειξη έδειχνε την **εσωτερική**
   διαδρομή (`/api/partner/v1/…`), άρα έλεγε «πρέπει να αρχίζει με /v1/» ακόμη κι όταν ο καλών το
   είχε γράψει σωστά.
2. **`involves_new` δεν άναβε ΠΟΤΕ** όταν ο καλών στέλνει «Ιβουπροφαίνη 400mg»: το ταίριασμα ήταν
   «όλη η συμβολοσειρά μέσα στο a/b», ενώ η απάντηση μιλά για τη δραστική. Χανόταν ακριβώς η
   πληροφορία «αυτό το προκάλεσε το καλάθι». Τώρα ταίριασμα με λέξεις ≥4 γραμμάτων.
3. **Ο έλεγχος «καμία παράμετρος tenant» εξαιρούσε ΟΛΟΚΛΗΡΟ το `v1.py`** — δηλαδή δεν φύλαγε ούτε
   ένα endpoint. Τώρα στοχεύει τους χειριστές HTTP (`@router.*`) και αφήνει τους εσωτερικούς
   βοηθούς, που *οφείλουν* να παίρνουν `tenant_id` από το κλειδί.
4. **`pos_sales.insert_one(doc)`** δεν έδειχνε το `tenant_id` στη γραμμή του. Διόρθωσα τον **κώδικα**,
   όχι τον έλεγχο.
5. **Ο έλεγχος στην αγωγή θα δινόταν με σκέτο `pharmacat`** — είναι ξεχωριστό πληρωμένο πρόσθετο
   (`drug_interactions`). Το API θα χάριζε από την πίσω πόρτα ό,τι πουλάμε από την μπροστινή.
6. **Εννέα δοκιμαστικά κλειδιά** από νωρίτερα σήμερα είχαν μείνει στη βάση — και **ένα ήταν ακόμη
   ενεργό** (μη ανακληθέν) σε πραγματικό φαρμακείο. Σβήστηκαν όλα.

### Κανόνας έκδοσης API (οδηγία ιδιοκτήτη, τέλος συνεδρίας)

«Ό,τι αλλαγές κάνουμε στο API να αλλάζουμε και την version στο Swagger.» Είχα προσθέσει 9
endpoints και το Swagger έλεγε ακόμη `1.0.0`.

- `API_VERSION` = **μία πηγή αλήθειας** στο `app/api/partner/app.py` → 1.0.0 **→ 1.1.0** (MINOR:
  νέα endpoints, συμβατά).
- Νέες ενότητες Swagger: **§9 Versioning** (τι σημαίνει PATCH/MINOR/MAJOR *για τον καλούντα*) και
  **§10 Changelog** (New/Changed/Fixed για το 1.1.0, + 1.0.0).
- **Το `/v1/ping` δεν επέστρεφε έκδοση** — είχα γράψει στο Swagger «κατέγραψε το `api_version` από
  το ping», δηλαδή η τεκμηρίωση θα έλεγε ψέματα. Προστέθηκε πεδίο `api_version`, από το **ίδιο**
  `API_VERSION` ώστε να μην μπορούν να διαφωνήσουν.
- Έλεγξα και τις **δύο σειρές εισαγωγής** (app→v1 και v1→app) για κυκλική εξάρτηση: καθαρό, γιατί
  το `app.py` εισάγει τον router **μέσα** στη `create_partner_app()`.
- **2 νέοι έλεγχοι** το επιβάλλουν: ανεβασμένη έκδοση χωρίς γραμμή changelog → κόκκινο·
  Swagger και ping να διαβάζουν την ίδια σταθερά. **25/25 πράσινοι.**
- Επαλήθευση ζωντανά: Swagger `1.1.0`, 10 ενότητες, 2 εγγραφές changelog, `ping.api_version=1.1.0`.
  Το δοκιμαστικό κλειδί σβήστηκε — **0 κλειδιά** στη βάση.
