# Προς CloudOn — ενεργοποίηση γέφυρας RxVision (5 λεπτά)

## Τι ζητάμε
Να τρέχει **αυτόματα κάθε 10 λεπτά**, στη **LIVE** βάση, η συνάρτηση `run()` του Advanced
JavaScript module **`rxvision / softone-pull-bridge`** (είναι ήδη ανεβασμένο).

## Γιατί έτσι (και όχι με web services)
Το domain `cloudon.oncloud.gr` είναι κοινό μεταξύ **live και R&D** (ίδιος σειριακός) και αυτή τη
στιγμή δείχνει στην **R&D**. Κάθε εισερχόμενη κλήση στη live επιστρέφει **404** — το επιβεβαιώσαμε:

| Δοκιμή | Αποτέλεσμα |
|---|---|
| `POST https://webdemo.oncloud.gr/s1services` (demo τεκμηρίωσης) | **200** «Please login first» |
| `POST https://cloudon.oncloud.gr/s1services` | **404** |
| `POST .../s1services/JS/rxvision/connector.createInvoice` | **404** |

Δηλαδή το αίτημά μας είναι σωστά διαμορφωμένο — απλώς **δεν υπάρχει πόρτα προς τη live**.

Γι' αυτό **αντιστρέφουμε τη ροή**: η live καλεί **προς τα έξω** εμάς. Δεν χρειάζεται αλλαγή DNS,
ούτε άνοιγμα εισερχόμενης πρόσβασης, ούτε πρόσβαση σε βάση.

## Τι κάνει το script (ανά εκτέλεση)
1. `X.HTTPCALL` → `GET https://app.rxvision.gr/api/v1/softone/pull` — παίρνει τα εκκρεμή παραστατικά
2. `X.WEBREQUEST` → `{SERVICE:"setData", OBJECT:"SALDOC"}` — τα εκδίδει **εσωτερικά** (πλήρης
   φορολογική διαδικασία → κανονικό ΜΑΡΚ)
3. `X.HTTPCALL` → `POST https://app.rxvision.gr/api/v1/softone/ack` — μας επιστρέφει findoc/ΜΑΡΚ ή σφάλμα

Ιδεμποτεντικότητα μέσω **POSGUID** = το `ref` του παραστατικού μας → **αποκλείεται διπλοέκδοση**
ακόμη και σε επανάληψη μετά από timeout.

## Τι χρειαζόμαστε από εσάς

**1. Σημείο εισόδου + χρονοπρογραμματισμός.** Ο Scheduler (Tools → System → Scheduled Jobs) τρέχει
Batch jobs (Dialog objects / SBSL). Επιλέξτε ό,τι ταιριάζει στην εγκατάσταση — μενού, κουμπί ή
SBSL wrapper — αρκεί να καλείται η `run()` **κάθε 10 λεπτά**.

**2. Εξερχόμενη πρόσβαση.** Ο application server της live πρέπει να φτάνει στο
`https://app.rxvision.gr` (443). Αν υπάρχει firewall, χρειάζεται άνοιγμα.

**3. Δοκιμή πριν τον προγραμματισμό.** Εκτελέστε πρώτα την `testConnection()` — καλεί μόνο
`/ping`, **δεν εκδίδει τίποτα**. Αναμενόμενο: «Σύνδεση OK. Εκκρεμή παραστατικά: N».

## ⚠️ Σειρά παραστατικού
Στο `CFG.SERIES` του script:

| id | Τι είναι | ΜΑΡΚ |
|---|---|---|
| **7767** | ΧΤΠΥ «Τιμολόγιο Παροχής Υπηρεσιών» | ✅ διαβιβάζεται |
| 7002 | ΠΡΤΙΜ «Προτιμολόγιο» | ❌ δεν διαβιβάζεται |

Άκυρο SERIES **δεν** πέφτει σε default — σπάει τη δημιουργία με μήνυμα «Δεν έχετε συμπληρώσει το
πεδίο *Υλικό*», που φαίνεται εντελώς άσχετο. Αν εμφανιστεί, ελέγξτε **πρώτα** τη σειρά.

## Ασφάλεια
Κοινό μυστικό σε header `X-S1-Token` (ήδη καταχωρημένο στο `CFG.TOKEN`). Δίνει πρόσβαση **μόνο**
στα δύο endpoints της γέφυρας. Ανακαλείται άμεσα από το adminpanel μας αν χρειαστεί.
