# «Τι νέο υπάρχει» Κύπρου — έκδοση **1.7.0**

Στο /admin/release-notes: Αριθμός έκδοσης **1.7.0** · **Για: 🇨🇾 Κύπρος**.

1. **Ο Σύμβουλός σου**
   Δες κάθε μέρα ποιοι πελάτες χρειάζονται κάτι — είδη που δεν δόθηκαν, φάσεις που καθυστερούν, πελάτες που σταμάτησαν να έρχονται — με όνομα και τηλέφωνο.
   Πού: Ο Σύμβουλός σου

2. **Κρυφό κόστος**
   Δες ανά μήνα πόσες συνταγές χάθηκαν πριν ολοκληρωθούν και πόσα είδη δεν δόθηκαν.
   Πού: Ο Σύμβουλός σου → Κρυφό κόστος

3. **Σημείωμα πάγκου στην Εικόνα Πελάτη**
   Τη στιγμή που ο πελάτης είναι μπροστά σου, δες τι του λείπει και τι να του θυμίσεις.
   Πού: Εξυπηρέτηση πάγκου → Patient Intelligence → Εικόνα Πελάτη
