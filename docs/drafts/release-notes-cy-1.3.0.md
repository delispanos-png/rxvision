# «Τι νέο υπάρχει» Κύπρου — έκδοση **1.3.0**

Στο /admin/release-notes: Αριθμός έκδοσης **1.3.0** · **Για: 🇨🇾 Κύπρος**.

1. **Θεραπευτικό προφίλ πελάτη**
   Δες σε ποιες θεραπευτικές κατηγορίες ανήκει κάθε πελάτης (υπέρταση, διαβήτης, χοληστερίνη…) από τα φάρμακά του.
   Πού: Εξυπηρέτηση πάγκου → Patient Intelligence → Εικόνα Πελάτη

2. **Πρόγραμμα λήψης και συνέπεια**
   Δες πόσο συνεπής είναι ο πελάτης σε κάθε φάρμακο και άναψε υπενθυμίσεις λήψης για λογαριασμό του.
   Πού: Εξυπηρέτηση πάγκου → Patient Intelligence → Εικόνα Πελάτη

3. **Μετρήσεις**
   Κατέγραψε πίεση, σάκχαρο και βάρος του πελάτη, με ιστορικό.
   Πού: Εξυπηρέτηση πάγκου → Patient Intelligence → Εικόνα Πελάτη

4. **Σύμβουλος Διατροφής**
   Δώσε στον πελάτη πρόταση διατροφής για τα φάρμακα που παίρνει: τύπωσέ τη, στείλ' τη ή ανάρτησέ τη στην πύλη του.
   Πού: Εξυπηρέτηση πάγκου → Διατροφή
