# «Τι νέο υπάρχει» Κύπρου — έκδοση **1.5.0**

Στο /admin/release-notes: Αριθμός έκδοσης **1.5.0** · **Για: 🇨🇾 Κύπρος**.

1. **Θεραπευτικές κατηγορίες πελατών**
   Δες πόσους πελάτες έχεις σε διαβήτη, πίεση, χοληστερίνη και άλλες θεραπείες, και πόσοι μπορούν να λάβουν μήνυμα.
   Πού: Marketing → Θεραπευτικές κατηγορίες

2. **Dashboard προώθησης με έτοιμες προτάσεις**
   Δες σε ποιους αξίζει να μιλήσεις σήμερα και στείλε με ένα κλικ.
   Πού: Marketing → Dashboard

3. **Καμπάνιες ανά θεραπεία**
   Στείλε μήνυμα φροντίδας σε όσους παίρνουν φάρμακα μιας θεραπείας, π.χ. υπέρτασης.
   Πού: Marketing → Καμπάνιες → Νέα καμπάνια

4. **Αυτόματα μηνύματα**
   Βάλε μηνύματα να φεύγουν μόνα τους: σε όσους δεν ήρθαν καιρό, σε νέους πελάτες, σε όσους μπήκαν στην εφαρμογή.
   Πού: Marketing → Καμπάνιες → Αυτοματοποιημένες
