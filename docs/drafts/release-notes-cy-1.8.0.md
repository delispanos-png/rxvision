# «Τι νέο υπάρχει» Κύπρου — έκδοση **1.8.0**

Στο /admin/release-notes: Αριθμός έκδοσης **1.8.0** · **Για: 🇨🇾 Κύπρος**.

1. **Σύγκριση προμηθευτών στην παραγγελία**
   Δες για κάθε είδος τον φθηνότερο προμηθευτή που το έχει και πόσα γλιτώνεις στην παραγγελία σου.
   Πού: Παραγγελία → Πρόταση παραγγελίας

2. **Μηνιαία απαίτηση ΟΑΥ**
   Δες πόσα περιμένεις να πληρωθείς κάθε μήνα και έλεγξε την εκκαθάριση με τη λίστα εκτελέσεων.
   Πού: Έλεγχος συνταγών → Πληρωμή ΟΑΥ → Μηνιαία απαίτηση ΟΑΥ

3. **Θεραπείες με Επανάληψη**
   Παρακολούθησε θεραπείες που επαναλαμβάνονται κάθε λίγους μήνες και δες ποιος καθυστέρησε.
   Πού: Marketing → Περιοδικές θεραπείες

4. **Σημείωση «απεβίωσε»**
   Σημείωσε πελάτη που απεβίωσε, ώστε να μη λαμβάνει μηνύματα και να βγει από τις λίστες ενεργειών.
   Πού: Διαχείριση φαρμακείου → Πελάτες → Καρτέλα πελάτη
