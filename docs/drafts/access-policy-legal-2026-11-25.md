# Πολιτική πρόσβασης: κείμενα για νομικό έλεγχο, πελάτες και DPIA (ΠΡΟΧΕΙΡΟ, 25/11/2026)

> Πρόχειρο για έλεγχο από τον ιδιοκτήτη και, όπου χρειάζεται, από νομικό σύμβουλο / DPO πριν δημοσιευτεί
> οτιδήποτε. Τεχνική περιγραφή των μέτρων: `docs/security-access-policy.md`.

---

## 1. Ρήτρα για τους Όρους Χρήσης

**Άρθρο Χ: Αυτοματοποιημένη πρόσβαση και εργαλεία τεχνητής νοημοσύνης**

1. Η πρόσβαση στην πλατφόρμα RxVision επιτρέπεται αποκλειστικά από φυσικά πρόσωπα, μέσω τυπικού
   προγράμματος περιήγησης (browser) ή της εφαρμογής, με τα προσωπικά τους διαπιστευτήρια.
2. Απαγορεύεται ρητά η πρόσβαση ή η επεξεργασία δεδομένων της πλατφόρμας μέσω:
   - προγραμμάτων περιήγησης ή εφαρμογών τεχνητής νοημοσύνης (ενδεικτικά: ενσωματωμένοι browsers εφαρμογών
     AI, «agentic» browsers, επεκτάσεις browser που ενεργούν αυτόνομα)·
   - αυτοματοποιημένων εργαλείων, scripts, bots, headless ή scripted browsers·
   - οποιουδήποτε μηχανισμού μαζικής άντλησης ή αντιγραφής δεδομένων.
3. Απαγορεύεται η αποθήκευση, προώθηση ή εισαγωγή δεδομένων ασθενών από την πλατφόρμα σε υπηρεσίες
   τεχνητής νοημοσύνης ή σε άλλα συστήματα τρίτων εκτός πλατφόρμας.
4. Οι εξαγωγές δεδομένων (Excel, CSV, PDF) επιτρέπονται μόνο για επιχειρησιακά αναγκαίο σκοπό, εντός των
   ορίων που ορίζει η πλατφόρμα, και καταγράφονται.
5. Η πλατφόρμα εφαρμόζει τεχνικά μέτρα αποκλεισμού και ανίχνευσης. Παραβίαση του παρόντος άρθρου
   συνεπάγεται άμεση προσωρινή αναστολή πρόσβασης του λογαριασμού και, σε περίπτωση επανάληψης ή
   σοβαρής παράβασης, καταγγελία της σύμβασης.
6. Τα διαπιστευτήρια είναι προσωπικά. Απαγορεύεται η κοινή χρήση λογαριασμού από περισσότερα πρόσωπα.

## 2. Ρήτρα για τη Σύμβαση Επεξεργασίας (DPA, άρθρο 28 GDPR)

**Άρθρο Υ: Απαγόρευση διαβίβασης σε εργαλεία τεχνητής νοημοσύνης τρίτων**

Ο Υπεύθυνος Επεξεργασίας (το φαρμακείο) αναλαμβάνει την υποχρέωση να μη χρησιμοποιεί, και να μην επιτρέπει
στο προσωπικό του να χρησιμοποιεί, προγράμματα περιήγησης ή εργαλεία τεχνητής νοημοσύνης τρίτων για
πρόσβαση στα δεδομένα που φιλοξενεί η πλατφόρμα. Τα δεδομένα αυτά είναι, μεταξύ άλλων, δεδομένα υγείας
(άρθρο 9 ΓΚΠΔ). Μια τέτοια χρήση θα συνιστούσε διαβίβαση σε τρίτο, χωρίς νομική βάση και χωρίς σύμβαση
επεξεργασίας.

Ο Εκτελών την Επεξεργασία (CloudOn / RxVision) εφαρμόζει τεχνικά μέτρα αποκλεισμού τέτοιας πρόσβασης,
καταγράφει τα σχετικά συμβάντα και ενημερώνει χωρίς αδικαιολόγητη καθυστέρηση τον Υπεύθυνο Επεξεργασίας
για κάθε συμβάν που ενδέχεται να συνιστά παραβίαση δεδομένων (άρθρο 33 ΓΚΠΔ).

## 3. Ανακοίνωση προς πελάτες (email + ανακοίνωση στην εφαρμογή)

**Θέμα:** Νέα μέτρα προστασίας δεδομένων υγείας στο RxVision

Αγαπητέ συνεργάτη,

Το RxVision φιλοξενεί δεδομένα υγείας των πελατών σας, για τα οποία ο νόμος (ΓΚΠΔ) προβλέπει την αυστηρότερη
προστασία. Από σήμερα εφαρμόζουμε τρία νέα μέτρα:

1. **Δεν επιτρέπεται η πρόσβαση από browsers τεχνητής νοημοσύνης.** Το RxVision δεν ανοίγει από τον browser
   εφαρμογών όπως το Claude Desktop, το Comet ή το ChatGPT Atlas, ούτε από αυτοματοποιημένα εργαλεία. Αν δείτε
   το μήνυμα «Η πρόσβαση δεν επιτρέπεται», ανοίξτε το RxVision σε Chrome, Edge, Firefox ή Safari.
2. **Κάθε εξαγωγή φέρει υδατογράφημα.** Κάθε Excel, CSV ή PDF γράφει ποιος το έβγαλε και πότε, και
   καταγράφεται. Κάθε εξαγωγή έχει όριο 2.000 γραμμών· για περισσότερες, περιορίστε τα φίλτρα.
3. **Αυτοματοποιημένη πρόσβαση = προσωρινό κλείδωμα.** Αν εντοπιστεί λογαριασμός να λειτουργεί από
   αυτοματοποιημένο εργαλείο, κλειδώνει προσωρινά. Το ξεκλείδωμα γίνεται αφού επικοινωνήσουμε μαζί σας.

Η καθημερινή σας δουλειά στο RxVision δεν αλλάζει. Για οποιαδήποτε απορία, είμαστε στη διάθεσή σας.

## 4. Καταχώριση στο DPIA (τεχνικά και οργανωτικά μέτρα)

| Στοιχείο | Περιγραφή |
|---|---|
| Κίνδυνος | Μαζική εξαγωγή δεδομένων υγείας μέσω AI browser / αυτοματισμού, με διαβίβαση σε πάροχο AI τρίτης χώρας χωρίς νομική βάση. |
| Πιθανότητα (πριν) | Μέτρια. Τα εργαλεία είναι ευρέως διαθέσιμα· σε άλλο προϊόν παρατηρήθηκαν 1.317 αιτήματα/λεπτό από ενσωματωμένο browser AI. |
| Μέτρο 1 | Αποκλεισμός AI browsers / scripted browsers (user agent) σε σελίδες και API, πριν από την αυθεντικοποίηση, fail closed. |
| Μέτρο 2 | Ανίχνευση browser που ελέγχεται από πρόγραμμα (`navigator.webdriver`) → κλείδωμα 24 ωρών, ακύρωση συνεδριών, ειδοποίηση. |
| Μέτρο 3 | Όρια ρυθμού ανά χρήστη (αιτήματα/λεπτό, ώρα, λίστες, λεπτομέρειες) με strikes και κλείδωμα. Σε φάση μέτρησης από 25/11/2026. |
| Μέτρο 4 | Εξαγωγές: καταγραφή (χρήστης, οθόνη, φίλτρα, γραμμές, SHA-256 αρχείου), υδατογράφημα, όριο γραμμών, όριο ανά ημέρα. |
| Μέτρο 5 | Ξεκλείδωμα μόνο από διαχειριστή, με αιτιολογία· πλήρες αρχείο συμβάντων (`access_events`). |
| Υπολειπόμενος κίνδυνος | Εργαλεία που δουλεύουν μέσα στον κανονικό browser του χρήστη (επεκτάσεις) ή τραβούν στιγμιότυπα οθόνης δεν αναγνωρίζονται από τον user agent. Τα περιορίζουν τα όρια ρυθμού και οι συμβατικοί όροι (ρήτρες 1–2). |
| Ημερομηνία εφαρμογής | 25/11/2026 (μέτρα 1, 2, 4, 5)· μέτρο 3 σε επιβολή μετά από περίοδο μέτρησης. |
