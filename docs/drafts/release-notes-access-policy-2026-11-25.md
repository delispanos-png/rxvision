# «Τι νέο υπάρχει»: πρόχειρο (25/11/2026)

> Το δημοσιεύει ο ιδιοκτήτης από το adminpanel → «Τι νέο υπάρχει» (editor). Δεν δημοσιεύεται από εδώ.

**Τίτλος:** Πιο ασφαλείς εξαγωγές και προστασία από browsers τεχνητής νοημοσύνης

**Κείμενο:**
Τα δεδομένα των πελατών σας είναι δεδομένα υγείας, γι' αυτό προσθέσαμε δύο προστασίες:

- **Υδατογράφημα σε κάθε εξαγωγή.** Κάθε Excel, CSV ή PDF γράφει στην πρώτη γραμμή ποιος το έβγαλε και πότε.
  Κάθε εξαγωγή έχει όριο 2.000 γραμμών. Αν η λίστα σας είναι μεγαλύτερη, θα σας το πει· περιορίστε τα
  φίλτρα (π.χ. ανά μήνα) για τις υπόλοιπες.
- **Το RxVision δεν ανοίγει σε browsers τεχνητής νοημοσύνης** (π.χ. τον browser του Claude Desktop, Comet,
  ChatGPT Atlas) ούτε σε αυτοματοποιημένα εργαλεία. Χρησιμοποιήστε Chrome, Edge, Firefox ή Safari.

**Πού θα το βρείτε:** σε κάθε κουμπί «Εξαγωγή» (Excel / CSV / PDF), σε όλα τα κυκλώματα.
