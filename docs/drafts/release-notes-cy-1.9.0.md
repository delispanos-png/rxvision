# «Τι νέο υπάρχει» Κύπρου — έκδοση **1.9.0**

Στο /admin/release-notes: Αριθμός έκδοσης **1.9.0** · **Για: 🇨🇾 Κύπρος**.

1. **Οικογένειες**
   Δες σε μία οθόνη τι πήρε και τι εκκρεμεί για κάθε μέλος μιας οικογένειας.
   Πού: Διαχείριση φαρμακείου → Οικογένειες

2. **Δομές φροντίδας**
   Οργάνωσε τους τροφίμους ενός γηροκομείου: φάσεις που έρχονται, οδηγίες λήψης και λογαριασμός συμμετοχών.
   Πού: Διαχείριση φαρμακείου → Δομές φροντίδας

3. **Κουπόνι στις καμπάνιες**
   Στείλε κουπόνι έκπτωσης με την καμπάνια σου και μέτρησε πόσοι το εξαργύρωσαν.
   Πού: Marketing → Καμπάνιες → Νέα καμπάνια
