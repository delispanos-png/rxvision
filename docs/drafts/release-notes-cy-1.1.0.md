# «Τι νέο υπάρχει» Κύπρου — έκδοση **1.1.0** (κυπριακή αρίθμηση)

Στο /admin/release-notes: Αριθμός έκδοσης **1.1.0** · **Για: 🇨🇾 Κύπρος**.

1. **Patient Intelligence**
   Δες ποιοι πελάτες σου χρειάζονται προσοχή: Dashboard, Σήμερα, Συμμόρφωση, Recall, Win-Back, Επιστροφές, VIP και Ρίσκο.
   Πού: Εξυπηρέτηση πάγκου → Patient Intelligence

2. **Εικόνα Πελάτη με αναζήτηση ταυτότητας**
   Βρες τον πελάτη με όνομα, αριθμό ταυτότητας ή ARC, κωδικό ΟΑΥ ή αριθμό συνταγής και δες όλη του την εικόνα.
   Πού: Εξυπηρέτηση πάγκου → Patient Intelligence → Εικόνα Πελάτη

3. **Πρόγραμμα λήψης στην πύλη πελατών**
   Οι πελάτες σου βλέπουν τα φάρμακα που παίρνουν με τη δοσολογία της συνταγής και παίρνουν ειδοποίηση την ώρα της δόσης.
   Πού: Πύλη πελατών (my.rxvision.gr) → Πρόγραμμα λήψης
