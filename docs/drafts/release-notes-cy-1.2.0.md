# «Τι νέο υπάρχει» Κύπρου — έκδοση **1.2.0**

Στο /admin/release-notes: Αριθμός έκδοσης **1.2.0** · **Για: 🇨🇾 Κύπρος**.

1. **Εκτελέσεις αυτόματα από την PharmacyOne**
   Αν δουλεύεις με PharmacyOne, οι εκτελέσεις ΓεΣΥ έρχονται μόνες τους κάθε ώρα, χωρίς αρχεία.
   Πού: Έλεγχος συνταγών → Εισαγωγή XML

2. **Εισαγωγή από φάκελο του υπολογιστή**
   Δείξε μία φορά τον φάκελο με τα XML και ανεβαίνουν μόνα τους, όσο το RxVision είναι ανοιχτό.
   Πού: Έλεγχος συνταγών → Εισαγωγή XML → Από φάκελο του υπολογιστή

3. **Έτοιμος κατάλογος ειδών Κύπρου**
   Πάρε τον κατάλογο της αγοράς με τιμές και ΦΠΑ, και κράτα τον ενημερωμένο κάθε βράδυ.
   Πού: Ρυθμίσεις → Ενημέρωση καταλόγου
