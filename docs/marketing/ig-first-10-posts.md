## Brand kit (για κάθε εικόνα)

| Στοιχείο | Τιμή |
|---|---|
| Primary | `#4f46e5` (brand-600) |
| Accent | `#7c3aed` (violet-600) |
| Σκούρο φόντο | `#0f172a` (slate-900) |
| Ανοιχτό φόντο | `#f6f7fb` (canvas) |
| Γραμματοσειρά | **Inter** — Bold για τίτλο, Regular για υπότιτλο |
| Μέγεθος | **1080×1350 (4:5)** — πιάνει περισσότερο χώρο στο feed |
| Λογότυπο | κάτω δεξιά, μικρό, πάντα ίδια θέση |

**Κανόνας συνοχής:** εναλλαγή **σκούρο → ανοιχτό → screenshot** ώστε το grid να «αναπνέει».
**Κανόνας ασφάλειας:** όλα τα screenshots από demo tenant, μηδέν πραγματικά ονόματα/ΑΜΚΑ.

## Πώς θα δείχνει το grid (3×3)

```
┌─────────┬─────────┬─────────┐
│ 10 σκ.  │  9 scr  │ 8 ανοι. │   ← τελευταία σειρά που ανεβαίνει
├─────────┼─────────┼─────────┤
│ 7 σκούρ │  6 scr  │ 5 ανοι. │
├─────────┼─────────┼─────────┤
│ 4 carou │  3 scr  │ 2 σκούρ │
└─────────┴─────────┴─────────┘
              1 (manifesto)
```
⚠️ Το Instagram δείχνει το **νεότερο πάνω-αριστερά**. Άρα ανέβασε με τη σειρά
1 → 10 και το grid θα διαβάζεται σωστά από κάτω προς τα πάνω.
